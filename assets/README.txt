# Ankylosaurus Game Assets

Состав архива:
1. Спрайт-лист анкилозавра 6x4:
   - строка 1: idle
   - строка 2: walk
   - строка 3: happy / victory
   - строка 4: sad / hurt

2. Декорации:
   - broadleaf tree
   - evergreen tree
   - magic tree
   - leafy bush
   - berry bush
   - flowering bush

3. Сундуки:
   - closed
   - open full
   - open empty

Фон изображений: ярко-розовый chroma key, примерно #FF00FF.
Его можно удалить при подготовке ассетов или использовать как transparent key в игровом движке.
